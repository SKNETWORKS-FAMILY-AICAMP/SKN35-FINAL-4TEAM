# 머신러닝 학습결과서

- 프로젝트: SlotAgent
- 작성 역할: ② 평가팩 및 채점 담당
- 작성일: 2026-11-25
- 상태: 학습용 그룹 교차검증·LightGBM 선정·저장 및 최종 평가1회 완료. 사람 라벨 검증은 미실시.

## 1. 목적

실행 기록의 특징으로 원본 자동 채점에서 오답으로 표시된 답을 우선 검토하는 보조 모델을 학습했다. 채택·기각 판정이나 최종 답의 사실성을 확정하는 채점기로 사용하지 않는다. 이번 실험은 현재 50유형 평가팩이 아닌 11/18 사전 실험 기록을 사용한다.

## 4. 교차검증 비교

아래 PR-AUC는 기존 metrics.py의 average_precision_score(AP) 값이며 사다리꼴 적분값과 구분한다. 95% 구간은 문항 단위 부트스트랩1,000회로 계산했다. 문항 유형 간 상관과 재학습 변동을 포함하지 않아 좁게 추정될 수 있고, 구간만으로 모델 간 유의한 우월성을 입증한 것은 아니다.

| 모델 | PR-AUC AP (95% 구간) | ROC-AUC | 오답 재현율 | 정밀도 | F1 | 검토 대상 비율 | 정확도 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 기준 모델 | 0.2093 (0.1373–0.2862) | 0.5000 | 0.00% | 0.00% | 0.0000 | 0.00% | 79.07% |
| 로지스틱 회귀 | 0.7490 (0.5467–0.9953) | 0.9650 | 80.09% | 83.41% | 0.8172 | 20.09% | 92.50% |
| LightGBM | 0.9205 (0.8437–0.9744) | 0.9668 | 80.09% | 78.35% | 0.7921 | 21.39% | 91.20% |

각 학습 모델의 임계값은 동일한 OOF 예측에서 오답 재현율80% 이상을 달성하는 가장 높은 점수로 골랐다. 이 예측으로 임계값을 고르고 재현율·정밀도를 함께 보고했으므로 낙관적일 수 있다. 점수는 확률 보정을 하지 않은 모델 출력이며 실제 오답 확률로 보장되지 않는다.

| 모델 | 임계값 |
|---|---:|
| 기준 모델 | 1.100000000000 |
| 로지스틱 회귀 | 0.959441563651 |
| LightGBM | 0.105032962491 |

**선정 결과: LightGBM.** PR-AUC 기준으로 가장 높았다. 다만 같은 재현율80.09%에서 로지스틱 회귀는 정밀도83.41%·검토비율20.09%로, LightGBM의 정밀도78.35%·검토비율21.39%보다 좋았다. 따라서 LightGBM이 모든 기준에서 우수하다는 결론은 내리지 않으며, 이번 선정은 미리 정한 PR-AUC 기준의 선택이다.

LightGBM의 OOF 기준으로 231건을 검토 대상으로 표시했고, 원본 오답226건 중181건을 잡고45건을 놓쳤다. 정답854건 중50건을 오답 위험으로 표시했다. 이는 사람 확인 결과가 아니라 자동 라벨과의 대조다.

| 원본 자동 라벨 | 검토 대상으로 표시 | 표시하지 않음 |
|---|---:|---:|
| 오답 | 181 TP | 45 FN |
| 정답 | 50 FP | 804 TN |

## 5. 최종 평가

2026-11-25 사용자의 LightGBM 선정·최종 평가 실행 요청 후 `evaluate.py --final`을 **1회** 실행했다. 학습된 모델을 그대로 사용했고 재학습·임계값 조정은 하지 않았다. 임계값은 학습용 OOF에서 정한 0.10503296249147699로 고정했다. 이 점수는 보정된 실제 오답 확률을 뜻하지 않는다.

최종 평가 대상은 학습에 포함하지 않은 T3·T7·C1의 468건(13문항·3유형)이며, 자동 라벨상 오답56건·정답412건이다.

**전체 재현율94.64%가 모든 유형의 성능을 뜻하지 않는다.** 오답56건 중51건이 T3에 몰려 있으며, T7에서는 오답5건 중2건만 탐지했다. 최종 평가와 OOF는 문항 유형·오답 비율이 달라 수치 상승을 모델 개선 효과로 해석하지 않는다. 문항 단위 부트스트랩 구간은 유형 간 상관·재학습 변동을 반영하지 않는다. 자동 라벨 기반의 작은 합성 실험이며 실제 운영 성능·사람 검증 완료를 뜻하지 않는다.

저장된 final_predictions.csv에서 성능 지표·혼동행렬을 다시 계산해 final_metrics.json과 일치함을 확인했다. 모델·학습 표·설정·학습 코드의 해시가 학습 당시와 같은 것도 확인했다. final_opened.log는1행이며 추가 평가·최종 평가 결과를 이용한 튜닝은 수행하지 않았다. 사람 오답50건·정답50건 확인은 남아 있다.

## 6. 해석

### 특징 중요도

학습용 전체에 재학습한 LightGBM의 gain 중요도다. 중요도는 인과적 원인이나 누출이 없다는 증명이 아니다.

| 특징 | Gain |
|---|---:|
| says_none | 11262.1268 |
| answer_len | 1795.6554 |
| n_tool_errors | 490.3720 |
| in_tokens | 481.6032 |
| out_tokens | 478.3966 |
| grounded_ratio | 352.1520 |
| n_empty_results | 329.0381 |
| n_tool_calls | 116.0715 |
| asks_back | 0.1628 |
| n_repeat_calls | 0.0000 |

says_none의 중요도가 가장 높다. 합성 실험에서 특정 답변 표현이 자동 채점 라벨과 강하게 연관됐을 가능성을 검토해야 한다. n_repeat_calls의 중요도0은 이번 데이터·모델에서 분할에 쓰이지 않았다는 뜻이며 일반적으로 불필요한 특징이라는 증거는 아니다.

### 도구 범위 밖 실패

제공자 기준에 따라 A_own이면서 scope_a=false인108건을 제외한 데이터로만 학습했다. 범위 밖 기록을 포함한 모델 성능은 이번에 비교하지 않았다. 최종 평가도 범위 밖108건을 제외한 지정468건에 대해서만 수행했다. 범위 밖 포함/제외 비교를 수행했다고 보고하지 않는다.

## 7. 한계와 결론

- 원본은 합성 업무 환경의 단일 LLM 실험이며, 학습용은8유형·33문항으로 작다. 반복 기록1,080건을 독립 문항1,080개로 세지 않는다.
- 원본 자동 채점은 글자 포함 여부에 기반하며 사람 라벨 확인은0건이다. 현재 성능은 이 자동 라벨을 예측한 결과다.
- 답변 표현·길이·잘린 도구 응답 등 실험 생성 방식의 특성을 학습했을 가능성이 있다. 의미적 사실성이나 근거 관계를 직접 판정하는 모델이 아니다.
- 임계값을 선택한 OOF에서 분류 지표를 보고했고 같은 비교로 모델도 선정했다. OOF 지표와 별도로 최종 평가1회 결과를 보고했다. 최종 평가도3유형·13문항의 합성 데이터이므로 실제 운영 일반화 성능으로 확정하지 않는다.
- 문항 단위 부트스트랩 구간은 유형 간 상관·모델 재학습 불확실성을 반영하지 않는다. C3처럼 약한 유형과 정확도가 더 높은 로지스틱 회귀도 함께 보고한다.
- LightGBM 기본 설정 비교만 수행했다. 튜닝, 확률 보정, 실제 사용자 로그 검증, 사람 라벨 검증은 하지 않았다.
- 학습 중 접근 차단으로 final.csv를 읽지 않았고 모델 확정 후 최종 평가를1회 수행했다. 사람 라벨 검증은 여전히0건이다. T7의 재현율40%와 자동 라벨 한계를 함께 보고한다.

결론: 이번 학습용 그룹 교차검증의 PR-AUC 기준으로 LightGBM을 선정하고 학습용 전체1,080건에 재학습하여 저장했다. 모델 확정 후 지정 최종 평가468건에서 PR-AUC0.9546·재현율94.64%·정밀도89.83%를 얻었으나 T7 재현율은40%였다. 사람 우선 검토를 돕는 후보 모델이며 제품 채점기나 채택·기각 판정에 적용하지 않았다.
